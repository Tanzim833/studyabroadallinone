# studyabroadallinone.com

বাংলাদেশি student-দের জন্য ফ্রি study abroad তথ্য। কোনো ads নাই, কোনো অ্যাকাউন্ট লাগে না।

---

## ⚡ সবচেয়ে জরুরি কথা

**তুমি শুধু `data` ফাইলগুলো edit করবে। বাকিগুলোতে হাত দেওয়ার দরকার নাই।**

| তুমি edit করবে | কী আছে এতে |
|---|---|
| `data.js` | ৩৯টা দেশের তথ্য + **trending তালিকা** |
| `universities-more.js` | বিশ্ববিদ্যালয়ের তালিকা |
| `programs.js` | কোর্স/প্রোগ্রামের তালিকা |
| `immigration.js` | Spouse, PR, নাগরিকত্ব + **৩ মাসের তারিখ** |
| `work.js` | স্টুডেন্টরা কী কাজ করে, মজুরি |

| হাত দিবে না | কেন |
|---|---|
| `app.js` | পুরো site এটা দিয়ে চলে |
| `styles.css` | ডিজাইন |
| `i18n.js` | বাংলা-ইংরেজি লেখা |
| `index.html` | মূল পাতা |

## ✏️ সবচেয়ে বেশি যে ৪টা কাজ করবে

### ১. নতুন university যোগ করা

`universities-more.js` খোলো। যেকোনো লাইনের নিচে এটা বসাও:

```js
U('University Name', 'romania', 'Cluj-Napoca', 'public', ['cs','business'], ['bachelor','master'], {moi:true}),
```

| অংশ | কী দিবে |
|---|---|
| `'University Name'` | বিশ্ববিদ্যালয়ের নাম |
| `'romania'` | দেশের slug — `data.js`-এ যেভাবে লেখা, হুবহু |
| `'Cluj-Napoca'` | শহর |
| `'public'` | `public` বা `private` |
| `['cs','business']` | বিষয় — নিচের তালিকা দেখো |
| `['bachelor','master']` | লেভেল — `bachelor` / `master` / `phd` |
| `{moi:true}` | MOI নিলে রাখো, না নিলে `{}` লেখো |

**বিষয়ের id:** `business` `cs` `engineering` `law` `medicine` `social` `arts` `science` `agri` `hospitality`

⚠️ **শেষে কমা `,` দিতে ভুলো না।**

---

### ২. নতুন program যোগ করা

`programs.js` খোলো। বিশ্ববিদ্যালয়ের নাম **হুবহু** মিলতে হবে:

```js
'University Name': [
  P('Computer Science', 'bachelor', 4, 'English', 'cs'),
  P('Business Administration', 'master', 2, 'English', 'business')
],
```

| অংশ | কী দিবে |
|---|---|
| `'Computer Science'` | কোর্সের নাম |
| `'bachelor'` | লেভেল |
| `4` | কত বছর |
| `'English'` | ভাষা |
| `'cs'` | বিষয়ের id |

**টিউশন যোগ করতে চাইলে** শেষে সংখ্যা দাও: `P('...', 'bachelor', 4, 'English', 'cs', 3000)`

❗ **বিশ্ববিদ্যালয়ের ওয়েবসাইটে নিজে দেখে নিশ্চিত না হওয়া পর্যন্ত টিউশন বসাবে না।** খালি থাকলে "নিশ্চিত হয়নি" দেখাবে — সেটাই সৎ।

---

### ৩. Trending দেশ বদলানো

`data.js` খোলো, `window.TRENDING` খুঁজো:

```js
window.TRENDING = [
  'romania', 'slovakia', 'cyprus', 'italy', 'lithuania', 'germany', 'hungary'
];
```

নাম যোগ করো, সরাও, বা ক্রম বদলাও — পুরো site আপনাআপনি বদলাবে।

❗ **কোনো দেশের ভিসা আটকে গেলে সেই সপ্তাহেই তালিকা থেকে সরাও।** নইলে ব্যাজটা মিথ্যা হয়ে যাবে — আর তখন এই site-টাও সেই জিনিস হয়ে যাবে যার বিরুদ্ধে এটা বানানো।

---

### ৪. ৩ মাসের তারিখ বদলানো

`immigration.js` এর একদম উপরে:

```js
window.SITE_UPDATED = { en: 'November 2026', bn: 'নভেম্বর ২০২৬' };
window.SITE_REVIEW  = { en: 'February 2027', bn: 'ফেব্রুয়ারি ২০২৭' };
```

প্রতি ৩ মাসে এই দুই লাইন বদলাও। সব পাতায় একসাথে আপডেট হবে।

## 🚨 ভুল হলে কী করবে

সাইট সাদা/ফাঁকা দেখালে — প্রায় সবসময় এই তিনটার একটা:

| ভুল | ঠিক করা |
|---|---|
| শেষে কমা `,` নাই | লাইনের শেষে কমা দাও |
| উদ্ধৃতি চিহ্ন `'` বন্ধ হয়নি | দুই পাশে `'` আছে কি না দেখো |
| ব্র্যাকেট `]` বা `)` বন্ধ হয়নি | গুনে দেখো খোলা আর বন্ধ সমান কি না |

GitHub-এ **History → আগের version → Revert** করলে সাথে সাথে আগের অবস্থায় ফিরে যাবে। কিছু হারাবে না।
